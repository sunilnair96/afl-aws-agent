Takeaways
  • The Gateway decides; your code makes the decision apply to the right person.
  • I found no harness option to forward the user's token (absence in what I read and tried, not proof).
  • The harness kept the conversation; the app sent only the new message on the same session.
  • A model refusing an injection is luck. The control is a tool with no user-id parameter.
  • A denial is HTTP 200 with an error in the body.
