Takeaways
  • Authentication (Cognito) and authorization (Cedar) are separate controls.
  • If the user and identity provider are the same, forward the token; don't fetch a second one.
  • Check the response body for a denial, not the HTTP status.
  • The rule stays outside the model and outside the tool code.
  • CodeZip builds read pyproject.toml, not requirements.txt.
